# T01：稳定资源身份与自动保护能力状态可见

## Parent

- 父 SPEC：[#66](https://github.com/williamxhero/CPA-Manager-Plus-ex/issues/66)。工作包 A；本票只引用该公开需求，不发布独立项目源码调查。

### Use Case

管理员需要知道当前资源的自动保护能力是否真实可用，且配置变化不能把状态串到另一资源。

## What to build

在管理 API 与凭证／provider 展示中建立同一稳定资源身份和能力状态。无独立门禁时如实显示“自动保护不可用”，不改手动开关、不宣称已受保护。此票交付可单独验证的能力读取闭环，而非只有内部表结构。

## Acceptance criteria

- [ ] API 返回实例范围、不透明资源 ID、身份／配置版本、查询与门禁能力、策略锁；包含人工关闭资源，不使用明文 Key、名称或数组位置作为持久身份。
- [ ] 配置重排、重命名不串号；换 Key／账户、删除重建、切实例及迟到响应有隔离测试；歧义绑定拒绝自动动作。
- [ ] 凭证／provider 的代表性展示点正确区分未知、不可用、正常；能力查询不访问平台上游，原手动开关、复制与定位保持兼容。
- [ ] 缺能力不回退写 disabled／排除模型，不把管理数据库 bool 当实际门禁确认。
- [ ] 管理鉴权、秘密诱饵、旧响应兼容、临时持久层与 UI 行为测试通过；记录增量迁移与回退方式。
- [ ] 若需 core 新能力，仅定义消费契约并由目标项目授权上下文实现；本项目不修改其他仓库。本轮只规划，后续部署需授权及 Hermes 独立验收。

## Blocked by

None (can start immediately)。真实自动保护不是本票的完成声明，后续专票验收。
