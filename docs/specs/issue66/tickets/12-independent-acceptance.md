# T12：本地完整链路与独立验收交接

## Parent

- 父 SPEC：[#66](https://github.com/williamxhero/CPA-Manager-Plus-ex/issues/66)；品牌子 SPEC [#68](https://github.com/williamxhero/CPA-Manager-Plus-ex/issues/68)。跨工作包最终交接，不替代任何既有验收。

### Use Case

管理员需要确认当前实际使用的全部 provider、凭证、运行模式与页面都满足原需求，而非仅有 fixture 演示或部分测试通过。

## What to build

将已交付切片连成可复验的本地管理 API→真实管理服务／临时持久层→隔离真实 core→受控协议上游的完整链路；在获得安全授权后补当前本地实例逐来源真实验证，形成绑定确切版本、可供 Hermes 独立复验的交接。

## Acceptance criteria

- [ ] 按父规格全部 18 项验收建立结果／证据索引；每项记录版本、环境、输入与外部行为，失败和未验证项目明确保留，不靠关闭子票代替完成。
- [ ] 隔离真实 core A/B 路由证明包含凭证与 provider、新尝试／重试／故障转移、实际适用流式／长连接、暂停中额度查询、人工意图隔离、精确金额边界和新证据恢复。
- [ ] 覆盖全库存小时刷新、来源 single-flight、失败旧值保留、多钱包／单位、身份变更／迟到响应、重启恢复／迁移回退、门禁失联及安全禁止行为；不 mock 被验收 selector 或自动状态机。
- [ ] Hermes 通过安全通道冻结当前本地 provider／凭证／模式清单；每个现存 provider 的真实余额查询、字段／权限／单位、小时任务与真实 gate 逐项有授权证据。无凭据或来源能力缺失保持阻塞，历史配置／fixture／新增测试平台不能替代。
- [ ] 所有适用 UI 渲染点和生成品牌资产实际渲染复核；品牌几何、字区保护、图标帧／副本／fallback、无双 EX 与幂等生成保留。
- [ ] 使用项目既有工具完成适用后端／前端／仓库回归、类型、lint、build、图标及生成校验；目标 core 测试由其 owner 提交版本证据；记录精确 head CI，不以筛选子集代替完整回归。
- [ ] 安全报告不含 Key／Cookie／原始响应或个人数据；本任务不连接 yosef-server、不处理小电脑 Qwen。当前规划轮不访问 live，后续真实查询须先有对应授权及安全通道。
- [ ] writer 自测与 Hermes 独立验收分离；交接允许带明确阻塞，不能宣称产品完成。没有本票自动获得的生产部署／重启／合并／关闭权限；备份、回退及显式发布授权门槛均保留。
